# 표 따오기 (Table to Sheet) — 개인정보처리방침

최종 업데이트: 2026-11-16 · 버전 0.3.0

## 요약

표 따오기는 **어떤 데이터도 수집·전송하지 않습니다.** 웹페이지의 표는 사용자의 브라우저 안에서만 처리됩니다.

## 처리하는 데이터

| 데이터 | 처리 방식 | 보관 |
|---|---|---|
| 웹페이지의 표 내용 | 확장 내부 메모리에서 감지·변환 | 저장하지 않음 (탭을 닫으면 사라짐) |
| 내보낸 파일(CSV/XLSX/JSON/MD) | 사용자가 선택한 폴더에 저장 | 사용자 파일 시스템 |
| 설정값(머리글/숫자 정리/병합셀 채우기) | `chrome.storage.local` | 브라우저 로컬에만 저장, 외부 전송 없음 |
| 클립보드 | 사용자가 [복사]를 누를 때 표 데이터 기록 | 운영체제 클립보드 |

## 하지 않는 것

- 서버·API로 데이터 전송 **없음**
- 계정·로그인 **없음**
- 분석 도구·광고·추적 픽셀 **없음**
- 제3자 판매·공유 **없음**
- 원격 코드 로드 **없음** (모든 코드는 확장 패키지에 포함)

## 권한과 목적

| 권한 | 목적 |
|---|---|
| `activeTab` | 사용자가 아이콘을 누른 탭에서만 동작 |
| `scripting` | 표 감지·추출 코드를 해당 탭에 주입 |
| `storage` | 옵션 기본값 저장 |
| `downloads` | 사용자가 요청한 파일 저장 |
| `contextMenus` | 표 우클릭 → 클립보드 복사 |
| `clipboardWrite` | 클립보드 복사 폴백 |

상시 접근 권한(host_permissions)은 요청하지 않습니다.
