## 상세 설명 (붙여넣기용)

```
웹페이지의 표를 골라 스프레드시트로 바로 옮기세요.

■ 이렇게 동작합니다
1. 툴바의 표 아이콘을 클릭합니다.
2. 페이지에서 찾은 표 목록(크기·미리보기)에서 원하는 표를 고릅니다.
3. [복사]를 누르면 Excel·구글시트에 Ctrl+V로 붙여넣을 수 있고,
   Excel(.xlsx)·CSV·JSON·Markdown 파일로 저장할 수도 있습니다.

■ 다른 확장과 다른 점
· 전 기능 무료 — 행 수 제한, 유료 잠금, 워터마크가 없습니다.
· 100% 로컬 — 표는 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다. 계정도 필요 없습니다.
· 병합셀 유지 — rowspan/colspan을 논리 그리드로 펼쳐 엑셀에서도 셀이 어긋나지 않습니다.
· 페이지 전체 수집 — '다음' 버튼이나 '더 보기'를 자동으로 눌러 최대 10페이지를 합칩니다. (URL이 바뀌는 이동형 페이지네이션은 안전하게 중단)
· iframe 지원 — 금융·공공 사이트처럼 표가 iframe 안에 있어도 찾아냅니다.
· 열 선택·셀 편집 — 내보내기 전에 필요한 열만 남기고 값을 고칠 수 있습니다.
· 숫자·날짜 정리 — 1,420 → 1420, ₩2,840,000 → 2840000, 2026. 11. 16. → 2026-11-16 (옵션)
· XLSX 내보내기 — 머리글 고정, 자동 필터, 숫자 서식, 실제 병합셀까지 지원합니다.

■ 지원하는 표
· <table> (머리글·행/열 병합)
· role="table" / role="grid" (ARIA)
· div 기반 카드형 그리드
· iframe 내부 표
· 지연 렌더·가상화 표 (현재 렌더된 행 기준)

■ 권한 안내
· activeTab: 아이콘을 누른 탭에서만 동작합니다.
· scripting: 표를 읽는 스크립트를 그 탭에만 주입합니다.
· storage: 옵션 기본값 저장.
· downloads: 내보낸 파일 저장.
· contextMenus / clipboardWrite: 표 우클릭 → 클립보드 복사.

■ 개인정보
표 내용은 브라우저 메모리에서만 처리됩니다. 서버 전송·계정·추적·광고가 없습니다.
자세한 내용: [개인정보처리방침 URL]

■ 문의
버그·요청: [지원 이메일]
```

## 단일 목적 (Single purpose)

```
웹페이지에서 사용자가 선택한 표를 스프레드시트 형식(클립보드·CSV·XLSX·JSON·Markdown)으로 내보내는 것.
```

## 권한 사유 (Permission justification)

| 권한 | 사유 (스토어 입력란용) |
|---|---|
| `activeTab` | 사용자가 툴바 아이콘을 클릭한 바로 그 탭에서만 표를 감지·추출합니다. 상시 접근 권한이 없습니다. |
| `scripting` | 표 감지·추출 코드를 해당 탭(및 그 iframe)에 주입하기 위해 필요합니다. 모든 사이트에 상시 주입하지 않습니다. |
| `storage` | 사용자가 설정한 기본값(머리글/숫자 정리/병합셀 채우기)을 저장합니다. |
| `downloads` | 사용자가 요청한 CSV·XLSX·JSON·MD 파일을 저장합니다. |
| `contextMenus` | 표 위 우클릭 메뉴에서 클립보드로 복사하는 경로를 제공합니다. |
| `clipboardWrite` | 우클릭 복사 시 클립보드 API가 차단되는 환경에서 문서 명령 폴백을 사용하기 위해 필요합니다. |

- **host_permissions 없음**: 어떤 사이트에도 상시 접근하지 않습니다.
