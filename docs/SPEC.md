# 표 따오기 (Table to Sheet) — MVP 명세

> 작성 2026-11-16 · 근거: `research/REVIEW-ANALYSIS.md` (경쟁 5개, 리뷰 49건)
> 목표: Chrome 웹 스토어 두 번째 게시 확장 (게시자 한도 1/3 사용 중)

## 0. 한 줄 정의

**"페이지의 표를 고르면 병합셀·숫자까지 맞춰 엑셀로. 전부 무료, 전부 로컬."**

- 카테고리: 생산성 · 워크플로 및 계획 (Workflow & Planning)
- 대상: 사무·리서치·마케팅 담당자, 대학생, 공공데이터를 다루는 실무자
- 정책: 사용자가 보고 있는 표를 사용자 조작으로 내보내는 기능 → 스크린샷·번역과 동급. 서버·업로드 없음

## 1. 경쟁 리뷰에서 확인된 기회

| 불만 | 비중(저평점 26건) | 우리 대응 |
|---|---:|---|
| 핵심 기능 유료화·행 수 제한 | **10건** | **전 기능 무료, 행 수 제한 없음** |
| 클릭해도 동작 안 함 | 5건 | 원클릭 감지 + 즉시 미리보기 + 실패 시 명확한 안내 |
| 보이는 표만 캡처(스크롤·페이지네이션) | 3건+ | **페이지네이션 자동 수집**, 스크롤 표 대응 |
| 동적 표·div-grid 미지원 | 3건 | `<table>` + `role=table/grid` + div-grid 휴리스틱 |
| 값 오류(1,420 → 1,42) | 3건 | 숫자·통화·날짜 정규화, 병합셀/헤더 정확 처리 |
| 업로드 방식 불신 | (긍정 리뷰 다수) | **100% 로컬**, 네트워크 요청 없음 |

## 2. 기능 범위

### P0 (v1.0 — 게시 필수)
1. 아이콘 클릭 → **표 자동 감지 목록** (개수, 행×열, 첫 행 미리보기)
2. 표 선택 → **그리드 미리보기** (병합셀 표시)
3. 내보내기: **클립보드(TSV)**, **CSV(UTF-8 BOM)**, JSON, Markdown — 전부 무료
4. 머리글 자동 감지(`thead`/`th`/`role=columnheader`) + 첫 행 머리글 옵션
5. 값 정규화: 앞뒤 공백·제로폭 문자 제거, 천단위 쉼표(`1,420`), 통화(₩/$), 날짜(YYYY-MM-DD)
6. 감지 실패 시 안내: "표를 찾지 못했습니다 — 표 위에서 우클릭 → 이 표 추출" (컨텍스트 메뉴)
7. 한국어/영어 UI, 다크 모드

### P1 (v0.2 — 완료)
8. ✅ **XLSX 다운로드** — 의존성 없는 OOXML 생성(병합셀·숫자 서식·머리글 고정·자동 필터)
9. ✅ **페이지네이션 자동 수집** — 다음/더 보기 자동 클릭, 최대 10페이지, 중복 행 제거, URL 이동 감지, 다른 표 버튼 오클릭 방지
10. ✅ **열 선택·셀 편집** — 열 칩으로 숨김/복원(모든 내보내기 반영), 셀 클릭 편집(Enter 저장·Esc 취소)
11. ✅ 컨텍스트 메뉴: 표 우클릭 → 클립보드(TSV)
12. ✅ **iframe 내부 표** — 모든 프레임 주입·프레임별 추출

### P2 (v1.2+)
12. 여러 표 한 번에 시트별 XLSX
13. 정기 수집(스케줄) — 추후 검토 (권한 최소화 유지)
14. Google Sheets로 복사(클립보드 경유) 가이드

## 3. UX 플로우

```
[아이콘 클릭]
  └ 팝업: "표 3개 발견" 목록 (제목/행×열/미리보기 3행)
      ├ 표 선택 → 그리드 미리보기 (병합셀 회색 표시)
      │   ├ [복사] → TSV 클립보드 (엑셀에 Ctrl+V)
      │   ├ [CSV] [JSON] [MD] → 파일 다운로드
      │   └ [Excel] (v1.1)
      └ 표 없음 → 안내 + 우클릭 메뉴 유도
[표 우클릭 → "이 표 추출"] (v1.0 포함, 감지 실패 대비)
```

## 4. 기술 설계

- **MV3, 빌드 없는 순수 JS** (의존성 최소화, 심사 리스크↓)
- 권한: `activeTab`, `scripting`, `storage`, `downloads`, `contextMenus` — **host_permissions 없음**
- 파일
  - `content/table-core.js` — 순수 로직(감지·추출·정규화·직렬화). `globalThis.TableCore` 노출, chrome 의존 없음 → 브라우저 테스트 가능
  - `content/content.js` — 팝업/컨텍스트 메뉴 메시지 글루
  - `popup/` — 목록·미리보기·내보내기 UI
  - `background.js` — 컨텍스트 메뉴 생성/클릭 처리
- **감지 알고리즘**
  1. `table` 요소 (중첩 표는 상위 우선, 레이아웃 표 제외: 셀 1~2개·면적 0)
  2. `[role="table"], [role="grid"]`
  3. div-grid 휴리스틱: 동일 자식 수(±1)를 가진 형제 3개 이상 + 각 자식이 2개 이상의 텍스트 블록
  4. 점수 = 보이는 면적 × 셀 수, 상위 20개만 노출
- **추출**: `rowSpan/colSpan` 그리드 정규화 → 앵커 셀에 값, 피복 셀은 `null` + 병합 정보 기록
- **정규화**: NBSP·제로폭 제거, `1,420` → 숫자 1420, `₩12,000` → 12000 + 통화, 날짜 ISO 변환(옵션)
- **직렬화**: TSV(탭/개행 이스케이프, Excel 붙여넣기 최적), CSV(RFC4180 + BOM), JSON, Markdown

## 5. 수용 기준 (Acceptance)

| # | 기준 | 검증 |
|---|---|---|
| A1 | `<table>` 표에서 행×열과 값이 원본과 일치 | 픽스처 비교 |
| A2 | `rowspan/colspan` 병합셀이 논리 그리드로 정확히 펼쳐짐 | 픽스처 단위 테스트 |
| A3 | div-grid(role 없는 카드 목록)도 표로 감지 | 픽스처 |
| A4 | `1,420` → 숫자 1420, `₩12,000` → 12000 | 단위 테스트 |
| A5 | TSV 복사 후 Excel 붙여넣기 시 열/행 유지 | 수동 확인 + 문자열 검증 |
| A6 | 탭에 표가 없으면 안내 문구 표시(무반응 금지) | E2E |
| A7 | 네트워크 요청 0건(오프라인 동작) | DevTools/E2E |
| A8 | 권한 최소(`activeTab` 등), host_permissions 없음 | manifest 검사 |
